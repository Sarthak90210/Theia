# Theia 0.1.0

First Windows x64 release.

- **Theia-Setup-0.1.0-x64.exe**: installer with an installation-folder choice,
  Start menu entry and desktop shortcut.
- **Theia-Portable-0.1.0-x64.exe**: run without installing.
- **SHA256SUMS.txt**: checksums for both downloads.

Browse an attached iPhone or local photo vaults, save selections and albums,
view photos and videos, play Live Photos on hover, browse burst frames and
choose their cover. The editor saves cropped and adjusted photos or trimmed
videos as copies. Vaults include Hidden and Recently Deleted collections.
Settings include a map privacy switch and keyboard-shortcut help.

FFmpeg 9.0.2, FFprobe, ExifTool and the image decoders are included.
Node.js and a separate FFmpeg installation are not required.

For USB iPhone access, install Apple Devices or iTunes to supply Apple's
drivers and Apple Mobile Device Service. Keep the phone unlocked and accept
Trust when asked. Phone contents are read-only. An iCloud-only original that
is unavailable over USB cannot be downloaded by this app.

This release is unsigned, so Windows may show an unknown-publisher prompt.
Uninstalling preserves the app profile and photo vaults. Search and automatic
updates are not included.

Validation: 284 automated tests and TypeScript checks passed. The packaged
runtime was checked separately for SQLite, image decoding, metadata extraction,
video tools, thumbnails and renderer/preload startup using generated fixtures.
The packaged build has not yet been qualified against a live iPhone.

Bundled software licenses and source links are in THIRD-PARTY-NOTICES.md and
the installed resources directory.
